# 大学课程表 UniversitySchedule

一款简洁实用的 Android 大学课程表 App，基于 Jetpack Compose + Material Design 3 构建。

## 功能概览

### 📅 课程表主页
- 按周查看课程安排，支持 **1~20 周** 快速切换
- 自动定位当前周，今日星期列高亮
- 课程格子按实际节数跨行显示，连续相同课程合并渲染
- 课程冲突区域以黄色卡片提示，点击查看冲突详情
- 上午/下午/晚上时段用分隔线区分

### ✏️ 课程管理
- 添加、编辑、删除课程，每门课独立配色（10 种预设色 + 自动分配）
- 支持为每门课设置多个时间段（教室、星期、节次、周次范围）
- 多选批量删除 + 全选/取消全选

### ⏰ 时间表设置
- 自定义每节课的名称和起止时间（如"第1节 08:30-09:15"）
- 支持添加/编辑/删除时间段，多选批量删除
- 时间段连续性校验防呆机制

### 📋 总体信息
- 设置总周数、学期开始日期、学校、专业

### 📦 数据导入导出
- 导出为 Markdown 文件（同时包含总体信息、时间表、课程安排）
- 从 Markdown 文件导入，覆盖式更新
- 也可在文件管理器中直接打开 `.md` 文件导入

### 🗑️ 出厂设置
- 一键删除所有数据（总体信息 + 时间表 + 课程安排），回到空白状态

## 技术栈

| 项目 | 技术 |
|------|------|
| 语言 | Kotlin |
| UI 框架 | Jetpack Compose + Material 3 |
| 构建工具 | Gradle (Kotlin DSL) |
| 最低版本 | Android 8.0 (API 26) |
| 目标版本 | Android 15 (API 35) |
| JDK | 17 |
| 数据存储 | SharedPreferences（自定义序列化） |

## 项目结构

```
UniversitySchedule/
├── app/src/main/java/com/schedule/app/
│   ├── MainActivity.kt      # 入口 Activity，处理 Markdown 文件导入 Intent
│   ├── ScheduleApp.kt       # 全部 UI 页面（主页、课程管理、设置、时间表等）
│   ├── CourseData.kt         # 课程数据模型 + Markdown 编解码器
│   ├── ScheduleData.kt       # 课程-时间段聚合模型 + 新旧格式转换
│   └── SlotData.kt           # 时间段数据模型 + 默认时间表
├── app/build.gradle.kts
└── settings.gradle.kts
```

## 编译方法

1. 用 **Android Studio**（Hedgehog 2023.1 或更新）打开项目根目录
2. 等待 Gradle 同步完成
3. 点击 ▶️ Run 或 Build → Build Bundle(s) / APK(s) → Build APK(s)

**APK 输出路径：** `app/build/outputs/apk/debug/app-debug.apk`

## Markdown 数据格式

导出的 `.md` 文件结构如下，可手动编辑后重新导入：

```markdown
# 大学课程表 — 完整数据

## 总体信息
| 总周数 | 学期开始日期 | 学校 | 专业 |
|--------|-------------|------|------|
| 18 | 2026-09-07 | 桂林理工大学 | 软件工程 |

## 时间表
| 名称 | 开始时间 | 结束时间 |
|------|----------|----------|
| 第1节 | 08:30 | 09:15 |
| 第2节 | 09:20 | 10:05 |

## 课程
| 课程名 | 教师 | 教室 | 星期 | 时间段 | 起始周 | 结束周 | 类型 | 学分 | 考核 | 开课单位 | 颜色 |
|--------|------|------|------|--------|--------|--------|------|------|------|----------|------|
| Linux操作系统 | 王新政 | 07220D | 2 | 第1-2节 | 1 | 12 | 必修 | 3 | 考查 | 计算机科学与工程学院 | auto |
```

### 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| 星期 | 1=周一 … 7=周日 | 整数 |
| 时间段 | 多个时间段用顿号连接 | `第1-2节` / `第1-2节、第3-4节` |
| 类型 | 必修 / 限选 / 任选 | |
| 考核 | 考查 / 考试 | |
| 颜色 | `auto` 自动分配，或 `#背景色,#文字色` | `#FF5252,#FFFFFF` |
