# 大学课程表 UniversitySchedule

> **当前版本：2.0** · Jetpack Compose + Material 3 · Android 8.0 (API 26) 及以上

一个轻量的 Android 大学课程表 App：课程表主页、上课提醒、节假日调休、Markdown 导入导出，外加外观自定义（深色模式 / 主题色 / 课表背景图片）。

本版是一次较大的升级，下面先讲 **升级内容**，再列 **本版修复的问题**，最后是功能一览与开发说明。

---

## 🚀 2.0 升级内容

### 新增功能

**① 首次启动引导**

七步：欢迎 → 导入课表 → 学期设置 → 时间表 → 添加课程 → 上课提醒 → 设置完成（除首尾两页外都能返回）。

- 「导入课表」二选一（导入文件 / 从零开始）；「学期设置」四项都要填满 —— 没选、没填满时「下一步」是灰的
- 「时间表」「添加课程」这两步可跳过，**跳过 = 这一步填的内容不保存**（会先弹窗确认）；其余步骤都有默认值，直接下一步即可
- 第 6 步不自动弹系统授权框，授权入口是「后台保活与闹钟权限」的第一项「系统通知」—— 点了才弹；这张卡把系统通知、精确闹钟、后台自启动、电池优化、最近任务加锁五项平铺出来

**② 上课提醒**

- 提前量可选：准点 / 提前 5、10、15、20、30 分钟（更大提前量走「自定义时间」）
- **三种提醒方式，互斥（不再出现两种通知同时说话）**，选择器是三个**等宽圆角方块按钮**（选中填主题色 + 主题色描边、文字自动黑白），与「外观设置 → 深色模式」同款：

  | 方式 | 行为 |
  |------|------|
  | 不启用通知 | 不发任何提醒 |
  | 普通通知 | 到点发通知，会响铃 / 震动；**课前、准点、下课各自一个通知类别**，可在系统设置里分别调声音与横幅 |
  | 焦点通知 | 全程只挂一条静默的常驻倒计时，不响铃；课前显示还有多久上课，课上显示还有多久下课 |

- 可选「下课时也提醒」，下课时通知下一节课安排
- 可选择是否提醒周末课程；提醒严格遵循课程周次范围与学期起止日期
- 基于 `AlarmManager#setAlarmClock`（可穿透 Doze 休眠），开机、修改系统时间、覆盖安装后均自动恢复排期
- 提醒页可预览未来 8 天的提醒列表；主页顶部常驻「下一节课」提示条
- **通知授权不自动弹**：入口是「后台保活与闹钟权限」（通知方式卡下面的一行入口，点开是弹窗）的第一项「系统通知」；未授权时页面另有一条醒目提示条
- 该弹窗五项依次为 **系统通知 / 精确闹钟 / 后台自启动 / 电池优化 / 最近任务加锁**，各带状态图标与「去开启 / 去设置 / 去加锁」
- 提供「测试通知」按钮与电池优化白名单入口，避免国产 ROM 省电策略冻结提醒

**③ 焦点常驻通知**

- 从设定的提前量那一刻起挂到连堂段下课，每分钟刷新剩余时间
- 标题写**状态 + 剩余分钟**（「还剩1小时30分钟下课」，精确到分钟），和右上角的秒级**系统倒计时**锚在同一个"到点时刻"上
- 心跳用 `setAlarmClock`（Doze 免疫，真做到每分钟刷新）—— 这是"标题能精确到分钟"的前提；代价是排期会走系统闹钟通道（部分 ROM 会在状态栏显示小闹钟图标）
- 正文两行：第一行课名，第二行 `时间段 · 节次 · 教室`
- 常驻不可右滑划走，「全部清除」也带不走；点「查看」跳转 App，点「关闭」才收起

**④ 节假日与调休**

- 设置放假日期区间与补课日（含「补哪天的课」）
- 课程表按调休自动重排，表头对应列显示 `休` / `补` 角标

**⑤ 其它**

- **外观设置**（侧边菜单 → **外观**）：页内可切**深色模式**（跟随系统 / 浅色 / 深色），并可换**主题色** —— 备选色与课程颜色同一份色板，最后给一个调色盘可自定义任意颜色；顶栏、按钮、选中态、开关、当天列高亮整套强调色跟着变，并有实时预览。应用里用到的颜色就是你点中的那块（不会被调暗），文字自动在黑/白之间切换保证看得清
- 出厂主题色 = 色板里的**「蓝」#29B6F6**（正是顶栏那块蓝），所以「恢复默认」得到的就是打开 App 时看到的样子；它本身就在备选色里，默认态显示为"选中的预设色"而不是落在自定义格上
- 侧边栏左下角有一个快捷图标，点一下按 **跟随系统 → 深色 → 浅色** 循环切换（手机=跟随系统、月亮=深色、太阳=浅色，图标本身就是当前状态）
- **课表背景图片**（外观设置 → 「课表背景图片」卡片）：开关默认关闭。打开后可选一张照片垫在课表底下，图片会**复制进应用私有目录**，之后删掉相册里的原图也不影响；**关掉开关图片保留**，再打开还是上次那张
  - 「遮盖强度」（默认 20%）：在图上压一层底色，防花哨图片把课表吃掉
  - 「课程色块透明度」（默认 0）：调高它课程色块会变淡、露出底图（**文字不受影响**，仍看得清）；**只在开着背景图时生效**，关掉背景图即恢复实心色块
  - 「图像位置编辑」：对着一个模拟课程表（版式与主页面完全相同）调图的位置，**双指捏合缩放、单指拖动平移**。图被裁掉的部分不用先放大，直接拖动就能挪进画面；位置**按全屏 / 小窗 / 分屏分别保存**，互不影响
- 自绘日期 / 时间选择器，风格与 App 统一
- 课程列表与课程详情里的时间段都支持拖拽排序
- 关于页与侧边栏的版本号改为动态读取，升级只改一处；关于页另有**「安装时间」**一行 —— 版本号永远是 2.0，用它来分辨手上装的是哪一次构建（报问题时先对一眼，避免拿旧包复测）
- **不申请任何存储权限**（见下方「权限说明」）：导入导出走系统文件选择器（SAF）、背景图走系统相册选择器，权限按 URI 临时授予；应用唯一自己落盘的是私有目录。换句话说，它没有能力往 `/sdcard` 等公共目录写东西（导出的 `.md` 除外，落点由用户在保存对话框里自己选）
- **开发者模式**（关于页连点「版本」8 次开启）：内含**测试课表**（读写切到独立的 `schedule_test` 文件，真实数据不受影响）与**焦点通知测试**（发一条 90 秒自动消失的焦点通知，验证系统是否支持息屏显示 / 超级岛）

### 交互与体验改进

- **切周动画**：由整页重排改为跟手双层翻页，配合对称 ease-in-out 曲线——拖拽跟手、落定柔和、快速连划不断层
- **主页手势分区**：只有课程显示区域左右滑动才切周；左侧边缘右滑才打开侧边栏，与竖向滚动、抽屉手势互不干扰
- **导入容错增强**：日期宽容匹配、允许缺少补课标记、段间外的行自动救回（详见下方「修复的问题」）

## 🐞 本版修复的问题（1.0 遗留）

| 问题 | 现象 | 处理方式 |
|------|------|----------|
| 切周卡顿 | 主页拖动切周时每帧都在重组整页课表，快速连划掉帧明显 | 拖动偏移改用 `FloatState` + `graphicsLayer` 延后读取，拖拽期间零重组；周次胶囊栏抽成独立作用域；翻页容器改用固定 3 槽位缓冲 |
| 侧边栏返回错乱 | 从其它页面返回主页时，侧边栏会自己弹开并盖住内容 | 返回不再自动改变抽屉开合状态，只保留手动开合 |
| 手势冲突 | 在主页任意位置左右滑都会切周，与竖向滚动、侧边栏手势互相打架 | 引入分区裁定：仅课程显示区域响应切周，左侧边缘右滑才开抽屉 |
| 导入丢课 | 日期写成 `2026/9/25`、`2026年9月25日` 等格式，或缺补课标记时，整段课程被直接丢弃 | 解析器改为宽容匹配多种日期写法；无补课标记、落在课程段之外的行也会被救回 |
| 导入报错不清 | 导入失败时只有一句「格式错误」，不知道哪一行出了问题 | 报错改为最多列出 4 条具体原因 + 总条数 |
| 导入时学期设置丢失 | 导出文件里的学期设置是 4 列（周数/开始日期/学校/专业），导入却要求至少 5 列才认 —— 这一段**从来没被导入成功过**，改完文件导回来学期设置还是老样子，且没有任何提示 | 列数判断改为 4 列即认；同时跳过表头行，避免把「学期开始日期」当数据读进去。JVM 验证：新旧两种格式 + 导出→导入往返，周数/日期/学校/专业全部正确 |
| 课程颜色选了不生效 | 编辑课程时能选颜色，但**选什么都没变化** —— 课表上的色块永远按课程顺序自动轮询色板 | `getCourseColor` 以前压根没用 `color` 参数，只按 index 取色。现在显式选过（含自定义）的颜色优先采用，只有 `auto` 才走自动分配。模拟器实测：把某门课改成橙色，色块像素从 (255,82,82) 变成 (255,145,0) |
| 课程色板有两个色几乎一样 | 第 4 个（绿 #66BB6A）和第 9 个（草绿 #8BC34A）色相只差十几度，摆在同一行里分不出来 | 第 9 个换成棕色 #8D6E63，色相/明度/饱和度都拉开；主题色备选与课程颜色共用同一份色板（`COURSE_SWATCHES`），改一处两处同步 |
| 本学期周数大于 20 周后翻不到 | 把本学期周数设成 22 周，课程表却只到第 20 周，第 21、22 周怎么滑都出不来 | 周次条原来写死了上限 20，现改为完全跟随「本学期周数」设置；本学期周数的合法范围在**引导页、学期设置页、Markdown 导入、周次条**四处统一为 1~52 周（一年 52 周），填得进去就显示得出来，填超了按 52 封顶 |

> 说明：以上只列 **1.0 版本中就存在、本版已修好** 的问题。2.0 开发过程中新功能自身出现并当场修掉的问题（例如开发期的渲染、通知异常）不在此表。

## 📖 功能一览

### 📅 课程表主页

- 按周查看课程安排，周次条跟随「本学期周数」设置（最多 52 周，即一年），左右滑动或点胶囊切换
- 自动定位当前周，今日星期列高亮
- 课程格子按实际节数跨行显示，连续相同课程合并渲染
- 课程冲突时点击课程卡片可查看冲突详情（提示有 N 节课程冲突）
- 上午 / 下午 / 晚上时段用分隔线区分
- 节假日列显示 `休` / `补` 角标，并按调休重排当天课程

### ✏️ 课程管理

- 添加、编辑、删除课程，每门课独立配色（10 色预设 + 调色盘自定义；选 `auto` 则按课程顺序自动分配并保持稳定）
- 支持为每门课设置多个时间段（教室、星期、节次、周次范围）
- 支持长按拖拽排序
- 多选批量删除 + 全选 / 取消全选

### ⏰ 时间表设置

- 自定义每节课的名称和起止时间（如「第1节 08:30-09:15」）
- 支持添加 / 编辑 / 删除时间段，支持拖拽排序、多选批量删除
- 时间段连续性校验等防呆机制

### 📋 学期设置

- 设置本学期周数（1~52 周）、学期开始日期、学校、专业

### 🔔 上课提醒

- 见上文「2.0 升级内容 → ② 上课提醒」

### 🎨 外观设置

- 入口是侧边菜单的「外观」（页面标题叫「外观设置」）
- 见上文「2.0 升级内容 → ⑤ 其它」：深色模式（含侧边栏左下角快捷切换）、主题色（备选色 + 调色盘）、课表背景图片（遮盖强度、图像位置编辑、按窗口形态分别保存位置）

### 🗓️ 节假日

- 见上文「2.0 升级内容 → ④ 节假日与调休」

### 📦 数据导入导出

- 导出为 Markdown 文件（同时包含学期设置、时间表、课程安排、节假日）
- 从 Markdown 文件导入，覆盖式更新
- 也可在文件管理器中直接打开 `.md` 文件导入

### 🗑️ 出厂设置

- 一键删除所有数据（学期设置 + 时间表 + 课程安排），回到空白状态

## 🔐 权限说明

只申请了 4 个权限，且都有明确用途 —— 没有位置、通讯录、相机、存储等敏感权限：

| 权限 | 用途 | 不授权会怎样 |
|------|------|--------------|
| `POST_NOTIFICATIONS` | 发上课提醒（Android 13+ 需授权） | 到点不会有任何通知弹出；其余功能正常 |
| `SCHEDULE_EXACT_ALARM` | 用 `setAlarmClock` 让提醒准点触发 | 退化成非精确闹钟，可能偏移（最多约 1 小时） |
| `RECEIVE_BOOT_COMPLETED` | 开机 / 覆盖安装 / 改时间后重新排期 | 重启手机后提醒可能不再触发，需手动打开一次 App |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 把 App 加入省电白名单（**可选**，由用户手动确认） | 国产 ROM 的省电策略可能冻结后台闹钟 |

**特别说明：不申请任何存储权限。** 导入 / 导出走系统文件选择器（SAF），背景图走系统相册选择器，都是按 URI 临时授权；应用自己落盘的只有私有目录。所以 `/sdcard` 等公共目录里出现的文件不可能来自本应用（用户主动导出的 `.md` 除外，落点由保存对话框决定）。

## 编译方法

1. 用 **Android Studio**（Hedgehog 2023.1 或更新）打开项目根目录
2. 等待 Gradle 同步完成
3. 点击 ▶️ Run，或 Build → Build Bundle(s) / APK(s) → Build APK(s)

命令行（Windows，`JAVA_HOME` 指向任意 JDK 17+ 即可，实测 Android Studio 自带 JBR 21 亦可）：

```bat
gradlew.bat assembleDebug     :: 日常调试
gradlew.bat assembleRelease   :: 交付用（走 debug 签名，见下）
```

**APK 输出路径：**

| 变体 | 路径 |
|------|------|
| debug | `app/build/outputs/apk/debug/app-debug.apk` |
| release | `app/build/outputs/apk/release/app-release.apk` |

> **关于 release 签名**：`release` 变体走的是 **debug 签名**，这样新包能**直接覆盖安装**、不会因换签名而被要求卸载（卸载会丢数据）。所以交付用 release（无调试工具、冷启动更快），它与 debug 包可互相覆盖。

## Markdown 数据格式

导出的 `.md` 文件结构如下，可手动编辑后重新导入：

```markdown
# 大学课程表 — 完整数据

## 学期设置
| 本学期周数 | 学期开始日期 | 学校 | 专业 |
|--------|-------------|------|------|
| 18 | 2026-09-07 | 桂林理工大学 | 软件工程 |

## 时间表
| 名称 | 开始时间 | 结束时间 |
|------|----------|----------|
| 第1节 | 08:30 | 09:15 |
| 第2节 | 09:20 | 10:05 |

## 节假日
| 名称 | 放假开始 | 放假结束 | 补课安排 |
|------|----------|----------|----------|
| 国庆节 | 2026-10-01 | 2026-10-07 | 2026-09-20→2026-10-06;2026-10-10→2026-10-07 |

## 课程
| 课程名 | 教师 | 教室 | 星期 | 时间段 | 起始周 | 结束周 | 类型 | 学分 | 考核 | 开课单位 | 颜色 |
|--------|------|------|------|--------|--------|--------|------|------|------|----------|------|
| Linux操作系统 | 王新政 | 07220D | 2 | 第1-2节 | 1 | 12 | 必修 | 3 | 考查 | 计算机科学与工程学院 | auto |
```

导入时日期格式是宽容的，`2026-10-01`、`2026/10/01`、`2026年10月1日` 都认。旧版导出的文件里这一段叫 `## 总体信息`、字段叫「总周数」，导入时两种标题都认。

### 字段说明

| 字段 | 说明 | 取值 |
|------|------|------|
| 星期 | 1=周一 … 7=周日 | 整数 |
| 时间段 | 多个时间段用顿号连接 | `第1-2节` / `第1-2节、第3-4节` |
| 类型 | 必修 / 限选 / 任选 | |
| 考核 | 考查 / 考试 | |
| 颜色 | `auto` 自动分配，或填 `#背景色,#文字色` | `#FF5252,#FFFFFF` |
| 补课安排 | 多个用 `;` 分隔，格式 `补课日→被补的那天` | `2026-10-11→2026-10-06` |

```
┌─────────────┐
│   主 页      │ ← 左侧边缘右滑 / 汉堡菜单 → 抽屉导航
│  (课程表)    │    课程显示区域左右滑动 = 切换周次
└──────┬──────┘
       │
  ┌────┴──────┐
  │  抽屉菜单  │
  ├───────────┤
  │  学期设置  │
  │  时间表设置 │
  │  课程管理  │
  │  节假日设置 │
  │  上课提醒  │
  │  外观      │ → 深色模式 / 主题色 / 课表背景图片
  │  设置      │ → 导入 / 导出 / 删除所有数据 / 关于
  │  使用手册  │
  └───────────┘
     左下角图标 = 快捷切换深色模式（跟随系统 / 深色 / 浅色 循环）
                 常驻左下角：分屏把窗口压得很矮时也不会被菜单挤掉
```

抽屉本身是自研的「跟手」实现（`EdgeDrawer.kt`）：左边缘右滑**跟着手指走**，快滑也能顺势拉开/收起，点右侧空白收起；菜单列表单独滚动，矮窗口（分屏）下八项菜单仍然够得到。

各页面只保留标题与控件，功能说明、注意事项统一收在「使用手册」里（入口只放侧边菜单一处；页面标题仍为「外观设置」，菜单项取短词「外观」）。

## ⚠️ 注意事项与已知限制

- **数据备份只有一条可靠途径**：在「设置 → 导出数据」存一份 Markdown。清除数据、卸载重装都会抹掉全部内容（背景图、提醒设置也一并清掉）。
- **划掉后台可能丢闹钟**：不少国产 ROM 在最近任务里划掉应用时会连带删掉它登记的闹钟，之后到点不响。请在最近任务里给本应用**加锁**（「后台保活与闹钟权限 → 最近任务加锁」有步骤），并把省电策略设为「不限制」。手机没有锁定功能可忽略。
- **通知渠道属性是"首次创建时定死"的**：声音、重要性、锁屏可见性创建后应用无法再改。因此版本升级时靠**换渠道 id 重建**来让新属性生效 —— 代价是老用户对这些渠道的自定义（比如换过的铃声）会回到默认，需要重新设一次。
- **焦点通知（息屏显示 / 超级岛）需要设备支持**：属厂商能力，未获支持的系统会静默忽略，应用侧已做兜底（亮屏锁屏 + 系统倒计时）。
- **API 26~32 的设备**：通知权限没有单独的开关（`POST_NOTIFICATIONS` 是 Android 13 才有的），相关引导项会退化为跳转系统通知设置页。
- **周数上限 52 周**：引导页、学期设置、Markdown 导入、周次条四处一致，超填按 52 封顶。
- **小窗 / 分屏**：系统会在窗口顶部中央画"⋯"把手，所有顶栏都做了 28dp 避让；小窗里底栏阴影会自动去掉，避免出现一条假的分层线。
- **安装被拦**：部分 ROM 会阻止静默安装（`INSTALL_FAILED_USER_RESTRICTED`），需在手机端允许一次。覆盖安装不会动数据。
